# Bharat Agrosmart

This workspace contains the Bharat Agrosmart project, a Next.js application for empowering Indian agriculture with AI.

## Project Structure

- `bharat-agrosmart/`: The Next.js application source code.

## Getting Started

1.  Navigate to the project directory:
    ```bash
    cd bharat-agrosmart
    ```

2.  Install dependencies:
    ```bash
    npm install
    ```

3.  Run the development server:
    ```bash
    npm run dev
    ```

4.  Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Deployment

This project is ready to be deployed on [Vercel](https://vercel.com/).
