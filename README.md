# Bharat Agrosmart

Bharat Agrosmart is a responsive agricultural platform designed to provide farmers with accessible digital tools and agricultural information through a simple, mobile-friendly interface.

## 🌐 Live Demo

**[Visit Bharat Agrosmart](https://bharat-agrosmart.vercel.app/)**

**[View HackSpace Project](https://www.commudle.com/builds/bharat_agrosmart)**

## 🚀 Features

- Disease Detection
- Market Prices
- Smart Advisory
- Responsive navigation
- Mobile, tablet, and desktop support
- Responsive layouts starting from 320px

## 🏆 Google HackSpace 2025

Bharat Agrosmart was selected for the **offline Grand Finale of Google HackSpace 2025**, organized by **GDG Noida and GDG Cloud Noida**.

The project was developed as an **AgriTech solution** focused on making agricultural information and digital tools more accessible to farmers.

## 🛠️ Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS

## 📱 Responsive Design

The frontend is optimized for mobile, tablet, and desktop screens, with responsive layouts starting from 320px.

The responsive implementation includes mobile navigation, adaptive typography, and responsive page layouts.

## ▶️ Run Locally

```bash
git clone https://github.com/s4chinjha/Bharat-Agrosmart.git
cd Bharat-Agrosmart
npm install
npm run dev
```

Open `http://localhost:3000`.
